# IWD-Image-web-downloader
When you download the installer, click the "встановити" button and select the necessary libraries
and then click the "далі" button, the installer will do everything itself and install everything in the folder WHERE IT IS LOCATED, and then open the "app" folder and run app.pyw, if there are any errors, then look at the "dependencies.md" file (in the repository)

To download images from the Internet with 1 button, you need to copy the URL of the image and paste it into the file /bin/web.LDLL (using any notepad), there will be 2 images from the installation, you can delete their URL, they are not required, if you get an error when downloading the image, then activate the URL_fix file, it will fix the URL

-----------україньска версія--------------

Коли ви завантажите інсталятор то натисніть кнопку "встановити" і виберіть потрібні бібліотеки 
а потім натисніть кнопку "далі" інсталятор все зробить сам і встановить все в папку ДЕ ЗНАХОДИТЬСЯ САМ а потім відкрийте папку "app" і запустіть app.pyw якщо виникли помилки то перегляньте файл "dependencies.md"(на репозиторії)

Для завантаження картинок з інтернету 1 кнопкою вам потрібно скопіювати URL адресу зображення та вставити його в файл /bin/web.LDLL(через будь-який блокнот) там з встановлення буде 2 картинки ви можете видалити їх URL вони не обовязкові якщо у вас виникає помилка при завантаженні картинки то активуйте файл URL_fix він виправить URL
